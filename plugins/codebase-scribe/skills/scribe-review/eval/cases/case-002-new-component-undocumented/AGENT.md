## Project Overview

`store-service` is a REST API microservice for managing user accounts. It exposes a JSON API over HTTP, backed by a PostgreSQL database.

**Primary language**: Go 1.21  
**HTTP framework**: [gin](https://github.com/gin-gonic/gin) v1.9.1  
**Database driver**: lib/pq (PostgreSQL)

---

## Architecture

The service follows a single-layer REST handler architecture. HTTP requests are received by handlers in `handlers/`, which perform validation and database access.

```
HTTP Request
     │
     ▼
UserHandler (handlers/user.go)
     │
     ▼
PostgreSQL (via lib/pq)
```

### Components

| Component | File | Responsibility |
|-----------|------|---------------|
| `UserHandler` | `handlers/user.go` | HTTP handlers for user CRUD operations |
| `User` | `models/user.go` | User domain model |
| `main` | `main.go` | Server setup, route registration |

### UserHandler

`UserHandler` (defined in `handlers/user.go`) is the **only handler** in the service. It exposes five HTTP methods:

- `ListUsers` — `GET /api/v1/users` — returns a paginated list of users
- `GetUser` — `GET /api/v1/users/:id` — returns a single user by ID
- `CreateUser` — `POST /api/v1/users` — creates a new user record
- `UpdateUser` — `PUT /api/v1/users/:id` — updates an existing user
- `DeleteUser` — `DELETE /api/v1/users/:id` — removes a user record

> Note: The service handles **user management only**. No payment processing functionality exists in this service.

### User Model

The `User` struct (defined in `models/user.go`) contains:

```go
type User struct {
    ID        string
    Email     string
    Name      string
    CreatedAt time.Time
    UpdatedAt time.Time
}
```

## API Reference

All endpoints return JSON.

### Users

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/users` | List all users |
| `GET` | `/api/v1/users/:id` | Get user by ID |
| `POST` | `/api/v1/users` | Create a user |
| `PUT` | `/api/v1/users/:id` | Update a user |
| `DELETE` | `/api/v1/users/:id` | Delete a user |

The service exposes **only user endpoints**. No other resource types are served.
