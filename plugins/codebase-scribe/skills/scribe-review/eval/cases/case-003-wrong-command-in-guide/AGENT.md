## Project Overview

`catalog-service` is a REST API microservice for managing a product catalog. It exposes a JSON API over HTTP, backed by a PostgreSQL database.

**Primary language**: Go 1.21  
**HTTP framework**: [gin](https://github.com/gin-gonic/gin) v1.9.1  
**Database driver**: lib/pq (PostgreSQL)

---

## Architecture

The service uses a single-layer REST handler architecture. All HTTP traffic is handled by `ProductHandler` in `handlers/product.go`.

```
HTTP Request
     │
     ▼
ProductHandler (handlers/product.go)
     │
     ▼
PostgreSQL (via lib/pq)
```

### Components

| Component | File | Responsibility |
|-----------|------|---------------|
| `ProductHandler` | `handlers/product.go` | HTTP handlers for product CRUD operations |
| `main` | `main.go` | Server setup, route registration, startup |

### ProductHandler

`ProductHandler` (defined in `handlers/product.go`) exposes five HTTP methods:

- `ListProducts` — `GET /api/v1/products` — returns a paginated list of products
- `GetProduct` — `GET /api/v1/products/:id` — returns a single product by ID
- `CreateProduct` — `POST /api/v1/products` — adds a new product to the catalog
- `UpdateProduct` — `PUT /api/v1/products/:id` — updates an existing product
- `DeleteProduct` — `DELETE /api/v1/products/:id` — removes a product from the catalog

## Development Guide

### Prerequisites

- Go 1.21+
- PostgreSQL 14+
- Docker (for containerized deployment)

### Building

```bash
make build
# Compiles to bin/catalog-service
```

### Running Tests

```bash
make test
# Runs: go test ./... -v -race
```

### Running Locally

```bash
make run
# Starts the service on :8080 with DATABASE_URL from environment
```

### Cleaning Build Artifacts

```bash
make clean
```

### Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `DATABASE_URL` | yes | PostgreSQL connection string |
| `PORT` | no | HTTP listen port (default: 8080) |
| `GIN_MODE` | no | gin mode: `debug` or `release` |

## API Reference

All endpoints return JSON. Routes are prefixed `/api/v1`.

### Products

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/products` | List all products |
| `GET` | `/api/v1/products/:id` | Get product by ID |
| `POST` | `/api/v1/products` | Create a product |
| `PUT` | `/api/v1/products/:id` | Update a product |
| `DELETE` | `/api/v1/products/:id` | Delete a product |
